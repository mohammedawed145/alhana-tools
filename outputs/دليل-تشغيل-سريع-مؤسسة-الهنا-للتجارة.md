# دليل التشغيل السريع
## مؤسسة الهنا لتجارة العدد وارد الامارات

## 1. مكونات الموقع

المشروع يتكون من تطبيقين منفصلين:

- **الفرونت اند:** React/Vite ويُفضل نشره على Vercel.
- **الباك اند:** Express/MongoDB ويُفضل نشره على Render.
- **قاعدة البيانات:** MongoDB Atlas.
- **الدفع:** InstaPay وVodafone Cash، مع مراجعة التحويل يدويًا من المدير.

## 2. التشغيل المحلي

### تشغيل الباك اند

من داخل مجلد `server`:

```powershell
cd "D:\my project\Poject Website\backend"
npm.cmd install
npm.cmd run seed
npm.cmd run dev
```

يعمل الباك اند افتراضيًا على:

```text
http://localhost:5000
```

اختبار صحته:

```powershell
Invoke-WebRequest http://localhost:5000/health
```

### تشغيل الفرونت اند

من مجلد المشروع الرئيسي في نافذة أخرى:

```powershell
cd "D:\my project\Poject Website"
npm.cmd install
npm.cmd run dev
```

تفتح الواجهة على:

```text
http://localhost:5173
```

## 3. إعدادات الفرونت اند

ملف الإعدادات المحلي:

```text
.env
```

القيم المطلوبة:

```env
VITE_API_URL=http://localhost:5000/api
VITE_INSTAPAY_ADDRESS=عنوان_إنستا_باي
VITE_VODAFONE_CASH_NUMBER=رقم_فودافون_كاش
VITE_WHATSAPP_NUMBER=رقم_واتساب_بالصيغة_الدولية
```

في الإنتاج، استبدل `VITE_API_URL` برابط الباك اند على Render، مثل:

```env
VITE_API_URL=https://alhana-tools-api.onrender.com/api
```

## 4. إعدادات الباك اند

ملف الإعدادات:

```text
backend/.env
```

القيم الأساسية:

```env
PORT=5000
MONGODB_URI=رابط_MongoDB_Atlas
JWT_SECRET=قيمة_عشوائية_طويلة
JWT_EXPIRES_IN=7d
CLIENT_URL=https://رابط-الفرونت-على-Vercel

ADMIN_EMAIL=بريد_المدير
ADMIN_PASSWORD=كلمة_مرور_قوية

WHATSAPP_NUMBER=رقم_واتساب_بالصيغة_الدولية
INSTAPAY_ADDRESS=عنوان_إنستا_باي
VODAFONE_CASH_NUMBER=رقم_فودافون_كاش
SHIPPING_FEE=150
RATE_LIMIT_MAX=300
```

لا ترفع ملفات `.env` إلى GitHub ولا ترسل كلمات المرور أو رابط MongoDB في المحادثات.

## 5. إعداد MongoDB Atlas

1. أنشئ Cluster على MongoDB Atlas.
2. أنشئ Database User.
3. اسمح بالاتصال من Render عبر Network Access.
4. استخدم رابط الاتصال في `MONGODB_URI`.
5. استخدم اسم قاعدة مثل `alhana-tools`.
6. تأكد أن الخطة تدعم Replica Set لأن إنشاء الطلب يستخدم MongoDB transaction.

بعد ضبط الرابط، شغّل:

```powershell
cd backend
npm.cmd run seed
```

هذا ينشئ أو يحدّث حساب المدير والتصنيفات الأولية.

## 6. نشر الباك اند على Render

1. أنشئ مستودع Git للمشروع وارفع الملفات.
2. في Render اختر **New > Blueprint** أو Web Service.
3. استخدم ملف `backend/render.yaml` الموجود في المشروع.
4. إذا أنشأت الخدمة يدويًا استخدم:
   - Root Directory: `backend`
   - Build Command: `npm ci`
   - Start Command: `npm start`
   - Health Check Path: `/health`
5. أضف Environment Variables المطلوبة من `backend/.env.example`.
6. أضف قيم MongoDB والمدير والدفع.
7. بعد النشر افتح:

```text
https://YOUR-RENDER-DOMAIN/health
```

يجب أن يعيد ردًا بصيغة JSON ويظهر أن الـAPI يعمل.

## 7. نشر الفرونت اند على Vercel

1. اربط مستودع Git بحساب Vercel.
2. أنشئ مشروعًا جديدًا من المستودع.
3. استخدم الإعدادات التالية:
   - Framework Preset: Vite
   - Build Command: `npm run build`
   - Output Directory: `dist`
   - Install Command: `npm ci`
4. أضف متغيرات البيئة:

```env
VITE_API_URL=https://YOUR-RENDER-DOMAIN/api
VITE_INSTAPAY_ADDRESS=عنوان_إنستا_باي
VITE_VODAFONE_CASH_NUMBER=رقم_فودافون_كاش
VITE_WHATSAPP_NUMBER=رقم_واتساب
```

5. نفّذ Deploy.
6. تحقق من فتح المسارات المباشرة مثل `/products` و`/login`. ملف `vercel.json` يوفر SPA fallback لهذه المسارات.

## 8. الربط بين Vercel وRender

بعد الحصول على رابط Vercel النهائي:

1. عدّل `CLIENT_URL` في Render إلى رابط Vercel الدقيق.
2. أعد تشغيل أو أعد نشر خدمة Render.
3. عدّل `VITE_API_URL` في Vercel إلى رابط Render مع `/api`.
4. أعد نشر Vercel.

مثال:

```env
CLIENT_URL=https://alhana-tools.vercel.app
VITE_API_URL=https://alhana-tools-api.onrender.com/api
```

## 9. اختبار ما بعد النشر

اختبر بالترتيب:

1. فتح الصفحة الرئيسية.
2. فتح `/products` مباشرة.
3. تحميل المنتجات من الـAPI.
4. إضافة منتج إلى السلة.
5. إنشاء طلب كزائر.
6. ظهور الطلب داخل لوحة المدير.
7. تسجيل الدخول من `/login`.
8. تأكيد الدفع من لوحة الإدارة.
9. تحديث حالة الشحن وإضافة رقم التتبع.
10. فتح رابط التتبع من صفحة النجاح أو الحساب.

## 10. اختبار MongoDB والدفع

### MongoDB

يُعتبر الاتصال ناجحًا عندما:

- يبدأ Render بدون خطأ اتصال.
- يعيد `/health` حالة HTTP 200.
- يعمل `npm run seed` بنجاح.
- يظهر الطلب الجديد داخل لوحة الإدارة.

تم التحقق محليًا من وجود قيمة `MONGODB_URI`، لكن الاختبار الفعلي المحلي لم يكتمل لأن الباك اند لم يفتح منفذ 5000 أثناء آخر محاولة تشغيل. يجب إعادة الاختبار بعد التأكد من صحة رابط MongoDB وNetwork Access.

### الدفع

المشروع لا يتصل بالبنوك ولا يتحقق من التحويل تلقائيًا. التحقق الصحيح يكون عمليًا عبر:

1. إنشاء طلب تجريبي.
2. تحويل رسوم الشحن إلى الحساب الفعلي.
3. إرسال الإيصال عبر واتساب.
4. دخول المدير إلى لوحة الإدارة.
5. تأكيد حالة الدفع يدويًا.
6. التأكد من منع تجهيز الطلب قبل تأكيد رسوم الشحن.

## 11. الحالة الحالية قبل النشر

- بناء الفرونت اند ناجح.
- اختبارات الباك اند 4/4 ناجحة.
- إعدادات MongoDB والدفع والمدير موجودة وغير فارغة محليًا.
- لم يتم تنفيذ نشر فعلي على Vercel أو Render بعد.
- لا يوجد تحقق بنكي تلقائي؛ المراجعة اليدوية مطلوبة.

## 12. إعداد GitHub قبل النشر

المشروع حاليًا غير مربوط بمستودع Git. أنشئ مستودعًا فارغًا على GitHub باسم مثل:

```text
alhana-tools
```

لا تنشئ README أو `.gitignore` من GitHub إذا كنت ستستخدم الأوامر التالية، حتى لا يحدث تعارض أولي.

من PowerShell:

```powershell
cd "D:\my project\Poject Website"

git init
git branch -M main
git add .
git status --short
```

قبل أول commit تأكد أن الملفات التالية لا تظهر في نتيجة `git status --short`:

```text
.env
backend/.env
node_modules/
dist/
backend/uploads/
```

أنشئ أول commit:

```powershell
git commit -m "Prepare Alhana Tools for deployment"
```

أضف رابط مستودع GitHub، مع استبدال `USERNAME` باسم حسابك:

```powershell
git remote add origin https://github.com/USERNAME/alhana-tools.git
git remote -v
git push -u origin main
```

سيطلب GitHub تسجيل الدخول أو Personal Access Token. لا تضع الـToken داخل الملفات أو داخل رابط محفوظ في المشروع.

للتحديثات اللاحقة:

```powershell
cd "D:\my project\Poject Website"
git add .
git status
git commit -m "Update Alhana Tools"
git push
```

للتأكد أن أي أسرار لم تدخل في Git:

```powershell
git ls-files .env backend/.env
```

يجب ألا يعرض الأمر أي ملف. ويمكن فحص الملفات التي سيتم رفعها عبر:

```powershell
git ls-files
```

## 13. ربط مستودع GitHub بالمنصات

### Render

- Repository: مستودع `alhana-tools`.
- Root Directory: `backend`.
- Build Command: `npm ci`.
- Start Command: `npm start`.
- Health Check Path: `/health`.
- Environment Variables: أدخل قيم `backend/.env` يدويًا في Render.

### Vercel

- Repository: مستودع `alhana-tools`.
- Root Directory: `.`.
- Framework: Vite.
- Build Command: `npm run build`.
- Output Directory: `dist`.
- Environment Variables: أدخل قيم `VITE_*` يدويًا في Vercel.
