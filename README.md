# مؤسسة الهنا لتجارة العدد وارد الامارات | Alhana Tools

متجر عربي RTL للأدوات ومعدات الورش باستخدام React/Vite وExpress/MongoDB.

## الحالة الحالية

- كتالوج منتجات مع بحث وفلترة وترتيب ومنتجات مميزة من الـAPI.
- سلة وشراء كزائر.
- رسوم شحن ثابتة قابلة للإعداد، مع InstaPay أو Vodafone Cash.
- دفع قيمة المنتجات عند الاستلام أو دفع كامل مقدمًا.
- حساب مدير ثابت لإدارة المنتجات والطلبات والرسائل والمستخدمين.
- العميل يرسل إيصال الطلب عبر واتساب بعد الشراء كزائر، والمدير يراجع الإيصال ويؤكد الدفع من لوحة الإدارة.
- الخادم يعيد قراءة الأسعار من MongoDB ويطبق السعر المخفض ويحجز المخزون داخل transaction.

## التشغيل محليًا

```bash
cd backend
copy .env.example .env
# املأ MONGODB_URI وJWT_SECRET وCLIENT_URL وبيانات الدفع
npm.cmd install
npm.cmd run seed
npm.cmd run dev
```

وفي نافذة أخرى من مجلد المشروع:

```bash
cd ../frontend
npm.cmd install
npm.cmd run dev
```

الواجهة تستخدم `/api` افتراضيًا، ويمكن ضبط `VITE_API_URL` عند تشغيل الواجهة والـAPI على نطاقين مختلفين.

## الاختبارات

```bash
cd backend
npm.cmd test
```

## نموذج الحسابات

العملاء يستخدمون الشراء كزائر. تسجيل العملاء معطل عمدًا، بينما تسجيل الدخول متاح لحساب المدير الذي يتم إنشاؤه من `ADMIN_EMAIL` و`ADMIN_PASSWORD` عبر `npm run seed`.

## الدفع والطلبات

رسوم الشحن تُدفع مقدمًا. بالنسبة للدفع عند الاستلام، يدفع العميل قيمة المنتجات للمندوب، أما رسوم الشحن فتظل مؤكدة مسبقًا. لا يوجد تحقق بنكي تلقائي؛ المدير يراجع الإيصال ويؤكد الحالة من لوحة الإدارة.

## النشر

استخدم `backend/render.yaml` لخادم Node أو `backend/Dockerfile` للحاويات. اربط MongoDB Atlas واضبط متغيرات `backend/.env.example`. يجب استخدام Cloudinary أو S3 أو Persistent Disk لتخزين صور المنتجات وإيصالات الدفع في الإنتاج؛ التخزين المحلي داخل `uploads` مناسب للتطوير فقط.

الواجهة تُنشر منفصلة على Vercel أو Netlify:

```text
Build command: npm ci && npm run build
Publish directory: dist
VITE_API_URL: https://YOUR-API-DOMAIN/api
```

قبل النشر، غيّر `JWT_SECRET` وكلمة مرور المدير، واضبط `CLIENT_URL` الدقيق، وأدخل بيانات الدفع الحقيقية، ثم نفّذ طلبًا تجريبيًا كاملًا.
